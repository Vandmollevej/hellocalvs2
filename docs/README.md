# HELLO CAL

Dansk mobil PWA til kalorie- og måltidsregistrering med AI-baseret foto-/talegenkendelse, stregkodescanning og en selvopbygget fødevaredatabase.

## Struktur

- [SPECIFICATION.md](SPECIFICATION.md) — samlet v1-specifikation (start her).
- [UI.md](UI.md) — skærmbilleder, navigation og gestures.
- [AI.md](AI.md) — billedgenkendelse, OCR, kamera og scanning.
- [DATABASE.md](DATABASE.md) — datamodel, produkter, stregkoder, opskrifter.
- [BACKEND.md](BACKEND.md) — hosting, API, synkronisering, GDPR.
- [ADMIN.md](ADMIN.md) — godkendelsesflow og administration.

Indholdet er rekonstrueret fra den fulde ChatGPT-designsamtale om appen (OCR'et PDF-eksport). Et tidligere forsøg på at eksportere specifikationen automatisk mislykkedes og efterlod tomme skabelonfiler — disse filer er genopbygget direkte fra samtalen for at rette op på det.
